
# DigiLearn - Digital Culture Courses Platform

A modern learning platform for university students to learn digital skills.

## Project Overview

DigiLearn is a web application built with React that provides university students with access to digital culture courses. The platform features course browsing, detailed course pages, and a responsive design.

## Technology Stack

- React 
- JavaScript
- React Router for navigation
- Tailwind CSS for styling
- Framer Motion for animations
- Shadcn UI components

## Features

- Browse courses by category
- View detailed course information
- Responsive design for all devices
- Interactive UI elements
